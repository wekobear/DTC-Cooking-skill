# 独立站检测清单

只检查用户范围内及为解释发现所需的项目，不强制全站、全部浏览器、固定竞品数量或问题数量。每项记录通过、失败、未执行或不适用，并附证据；不靠总分判断是否应上线。英文同版见 [Audit Checklist](audit-checklist.md)。

## 资料与数据可信度

- 先检查 PostHog、GA4 或后台的工具可调用、授权有效、目标站点匹配、相关数据可读；插件已安装不等于数据可用。
- 无连接时可用 PDF、表格、报表、数据文档或截图，记录来源、日期、页码/工作表和可读性。
- 都没有时按真实页面与相关标杆对照，保留体验观察，不填虚构指标。
- 使用数据时写清时间、时区、统计对象、分母、设备/渠道、漏斗顺序及缺失/重复事件；按问题选择必要明细。
- 对照站点现有事件定义，区分代码标记、浏览器请求和平台接收。后台订单不能还原未采集的浏览或放弃路径。
- 不同平台、日期或统计单位的数据未经核对不能直接比较；优先使用同站、同渠道、相近条件下的历史基线。
- 数据缺失只影响依赖它的结论，不阻塞独立界面检查或已复现缺陷修复。

## 流量与页面承接（相关且有证据时）

- 广告或搜索承诺与落地页实际内容相符。
- 按相关渠道和设备检查差异，不由总跳出率推断某个视觉元素造成流失。
- 新客与回访客差异结合来源和样本解释，不预设正常倍数。
- 市场、语言、币种、单位、配送和支付表达适配实际用户；不按国家或地区预设审美与信息密度。

## 看懂页面

- 页面清楚说明产品、适用场景、关键差异和下一步动作。
- 信息顺序服务当前购买任务，主次动作容易区分；弹窗不会挡住必要内容。
- 图片展示需要判断的产品、尺寸、细节或使用场景，并有来源。
- 价格、折扣、分期、库存和配送语言准确；保修、退换和客服信息在需要时能找到。
- 评价、认证和效果承诺有可核验依据，不为补全布局编造内容。
- 静态图片本身不是缺陷；动效仅在有助理解或反馈时使用，并考虑减少动态效果的偏好。

## 选定商品

- 导航、分类和商品卡帮助找到本次目标商品，链接与 SKU 正确。
- 对比信息、排序、筛选和推荐依据实际选购任务设计，空结果有返回或替代路径。
- 规格、变体、套装、订阅与数量选择能准确反映所购内容与价格。
- 切换选项不会误选、丢失输入或让购买按钮进入错误状态。
- 推荐配件与交叉销售有帮助且不阻挡主要购买动作。

## 完成购买

- 加购有明确的加载、成功和失败反馈；重复点击不会重复产生意外操作。
- 购物车商品、数量、价格、优惠与小计正确，修改后保持一致。
- 费用、配送范围和预计送达时间在可确定时清楚呈现，跨页面承诺一致。
- 结账方式、必填字段和支付选项适合目标用户；不必要的注册或输入有具体证据支持改进。
- 错误说明指出问题并帮助恢复；键盘焦点和已输入内容妥善保留。
- 真实购买、支付或对外通知验证遵循任务授权与测试环境，不能把静态演示当完成交易。

## 视觉、移动端与可访问性

- 在涉及的手机和电脑视口检查长文案、图片裁切、溢出、遮挡与布局抖动。
- 字号阶、行宽、对比度、间距和主次按钮让内容易读，沿用现有品牌规范。
- 触控目标、键盘导航、聚焦态、表单标签和错误状态可用。
- 固定栏、吸底按钮或弹层只在方案需要时采用，不遮住内容或系统安全区。
- 信息图片有有意义的替代文本；装饰图片可使用空 alt，并避免干扰辅助技术。
- 组件状态一致；需要修改时使用具体要求，不只写“高级”“有质感”。

## 技术与内容（按改动选择）

- 实际链接、图片、必要资源和受影响交互正常；成功 HTTP 状态不单独证明功能可用。
- 性能问题注明工具、设备、网络、测试日期及实验室/真实用户数据来源。
- 使用当前技术标准或项目预算时附来源；不把任意评分或页面体积当通用上线门槛。
- SEO 在范围内时检查标题、描述、标题层级、内链及存在的结构化数据；JSON-LD 可解析不证明内容正确。
- 事件沿用已有有效命名；有必要才新增，并核对触发时机、属性和去重。
- 区分静态检查、实际浏览器操作和生产检查；浏览器覆盖按本次变化与用户环境选择。

## 反馈与标杆

- 反馈记录实际场景、设备、来源和复现情况；单个严重故障也可立即修复，不等待反馈数量增长。
- 根据问题选相关标杆，区分同类竞品和跨品类参考，不强制固定数量或巡检周期。
- 每个引用保留具体 URL、日期、地区、视口、状态和真实截图，解释可借鉴与不适用部分。
- 不用生成图或搜索摘要代替实际页面证据，不复制标杆的价格、政策或商业承诺。

## 结论与交接

- 每项有稳定问题编号，区分已复现缺陷、体验风险和待验证增长假设。
- 记录问题 → 截图/资料 → 改法 → 组件/实现位置 → 验收动作，不凑数量。
- 按用户影响、证据强弱和工作量解释优先级；责任按实际团队填写。
- 无数据不承诺提升比例；已发布、功能可用和转化提升得到证实分别报告。
- 仅输出已执行节点的简短报告，未确认内容及其影响明确说明。
